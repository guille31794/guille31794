## Featured Project

### [LatencyTester](https://github.com/guille31794/latency_tester) — Video Surveillance Latency Measurement Device

A portable instrument for measuring end-to-end latency in real-time CCTV systems, built on Raspberry Pi 3 with a touch GUI.

**Highlights:**
- Qt 6.11 embedded application (C++20) with 7-screen touch interface
- Full ARM64 cross-compilation toolchain (GCC 13 + Qt from source + Docker)
- 147 automated unit tests, Valgrind-verified, zero memory leaks
- Multi-language UI (ES/EN/PL), dark mode, colorblind accessibility
- Containerized build: one command produces a production binary on any machine

`C++20` `Qt 6` `ARM64` `Docker` `Raspberry Pi` `pigpio` `libgpiod` `QTest` `Valgrind`
